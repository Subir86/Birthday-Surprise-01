BIRTHDAY PARTY WEBSITE

Page 3 runs a continuous 72-second, 13-scene animation. The supplied sticker assets are cropped into stickers/sticker-01.png through sticker-24.png. The sequence and fixed R, G, B, Y positions are defined in script_english.js; the cake, decorations, dialogue and character movement remain on the shared timeline.

The original uploaded sheets are preserved in stickers/source/ for reference.

The animation uses requestAnimationFrame, supports replay, and keeps the existing continue-to-cake action. Other pages, sound controls, progress indicator, quiz, and messages remain available.

RUN
Keep index.html, index_english.html, style.css, script_english.js, opening-animation.js and stickers/ together. Open index.html, which forwards to the English version. Open index.html in a browser or use VS Code Live Server.

SOUND
The existing sound effects are reused. Mobile browsers may require a tap before they allow sound playback.
